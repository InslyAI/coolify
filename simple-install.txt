To install custom Coolify:

Method 1 - Download and run:
wget raw.githubusercontent.com/kivilaid/coolify/v4.x/scripts/install.sh
sudo bash install.sh

Method 2 - Direct download:
sudo wget -O- raw.githubusercontent.com/kivilaid/coolify/v4.x/scripts/install.sh > install.sh
sudo bash install.sh

Method 3 - Using curl:
curl -fsSL raw.githubusercontent.com/kivilaid/coolify/v4.x/scripts/install.sh -o install.sh
sudo bash install.sh
